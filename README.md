# Now You Smell Me

A perfume explorer and recommender with a web interface built using Next.js.

## Requirements

* Node.js 18+

## Running the Next.js app

```bash
cd perfume-visualizer
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to explore the perfumes. Use the search box to filter by name or note, then click a perfume to see recommendations based on shared notes.
